Accessibility

Learning should be easier to access.

A+ Techucation works to improve access to its learning information and digital experiences.

Our goal

A+ Techucation, operated by A+ Techucation LLC, uses the Web Content Accessibility Guidelines as a reference for ongoing improvement across navigation, forms, text alternatives, responsive layouts, keyboard use and reduced-motion preferences.

Learning experience

  • Keyboard-accessible navigation and controls
  • Visible focus indicators
  • Semantic headings and labeled interactive elements
  • Reduced-motion support for animated AI teacher characters
  • Responsive layouts for smaller screens and magnification
  • Text-based alternatives to decorative motion and progress visuals

Need an accommodation?

If a lesson, page, assessment, document or member workflow creates a barrier, use the secure accessibility support route. Describe the task or content you need help accessing, but do not include unnecessary sensitive personal information.

Continuous improvement

Accessibility is an ongoing process. As course content, member tools, AI support and payment systems change, accessibility issues should be reviewed and prioritized based on impact and feasibility.
