# ATechSpot Website Build

Production-oriented static website starter for www.atechspot.com.

## Included
- Revenue-focused homepage
- Responsive design
- Accessible navigation
- SEO title/meta/canonical
- Organization + WebSite JSON-LD
- robots.txt + sitemap.xml
- Security headers for Vercel
- Growth assessment demo
- Working internal/external links
- Policy page placeholders

## Before Production
1. Replace policy placeholders with counsel-reviewed policies.
2. Connect the assessment form to your CRM/email backend.
3. Replace `mailto:?subject=...` Executive Review CTA with your real payment/intake flow.
4. Add approved logo/social links and Open Graph image.
5. Verify all sister-site URLs are live before launch.
6. Connect www.atechspot.com in hosting/DNS and verify Search Console + analytics.
