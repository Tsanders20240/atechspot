# ATechSpot AI Intro Website

Static production-ready front-end concept for https://www.atechspot.com/.

## Core features
- 10-second AI intro with Skip button
- Session-aware intro (does not replay every page refresh in same tab)
- prefers-reduced-motion support bypasses intro
- Revenue-focused homepage
- 20-property ecosystem directory with filters
- Working on-page business assessment
- SEO metadata + JSON-LD
- robots.txt + sitemap.xml
- Vercel security headers
- Responsive design
