# A+ Techucation V21 — Apple-Style Multi-Page Revenue Front End

V21 applies the premium layout system across the complete website while preserving all original page content, forms, functions, legal information, analytics and files.

## Front-end system

- Thin glass navigation
- Sticky service-category tabs
- Announcement and intake recommendation bar
- Centered full-width feature introductions
- Large single-focus image panels
- Two-column service tiles
- Apple-style typography, spacing, buttons and neutral surfaces
- Page-specific revenue calls to action
- Responsive mobile category scroller and action bar

## Functionality preserved

- All 39 HTML entry points
- Intake, contact, data-recovery, booking and payment workflows
- Careers and internship content
- Cloudflare form functions
- Analytics, chat and Messenger
- Privacy, terms, accessibility and affiliate disclosures
- DriveSavers content and downloadable ABCs activity book
- Sitemap, robots, headers and redirects

## Deploy

Extract the ZIP and upload every extracted file and folder to the existing Cloudflare Pages `atechspot` project. Do not upload the unopened ZIP and do not disconnect either custom domain.
