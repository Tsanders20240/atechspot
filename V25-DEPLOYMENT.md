# V25 Deployment

Deploy this folder as the production static site for A+ Techucation.

Canonical public URL: https://atechspot.com/
Preferred redirect: https://www.atechspot.com/* -> https://atechspot.com/$1

Do not create a redirect from the apex domain back to www.

V25 is a visual refresh over V24. Existing HTML, forms, functions, analytics, legal pages, resources, and service routes remain in place. The primary visual changes are provided by /assets/v25.css.
